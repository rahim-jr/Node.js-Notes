# Database Seeder and Docker Setup - B_3

## Seeder.js Function Flow

The seeder.js function executes in the following order:

1. **userSeeder** - Creates initial users
2. **userProfileSeeder** - Assigns profiles to users
3. **userUpdateSeeder** - Updates user information
4. **serviceSeeder** - Creates services
5. **permissionSeeder** - Creates permissions
6. **permissionServiceSeeder** - Links permissions to services

## Creating the MySQL Database

After completing the makefile, follow these steps to create the MySQL database:

### Access MySQL Container

```bash
# Get into MySQL container
docker exec -it mysql sh

# Connect to MySQL
mysql -h 127.0.0.1 -P 3306 -u root -p
```

Enter your password when prompted.

### MySQL Commands

Once inside MySQL, you can run the following commands:

```sql
-- Show all databases
show databases;

-- Use specific database
use <your database>;

-- Show all tables
show tables;
```

## Docker Management Commands

### Container Management
```bash
# Stop docker container
docker stop <container id>

# Remove docker container
docker rm <container id>

# Remove docker container forcefully
docker rm -f <container id>

# Remove docker image
docker rmi mysql
```

## Makefile Commands

Use the following commands to manage the database and application:

| Command | Description |
|---------|-------------|
| `runmysql` | Create and run the MySQL container |
| `startmysql` | Start the MySQL container |
| `stopmysql` | Stop the MySQL container |
| `createdb` | Create the `ecommerce` database |
| `dropdb` | Drop the `ecommerce` database |
| `seed` | Seed the database |
| `startserver` | Start the server |
| `startclient` | Start the client |

### Makefile Implementation

```makefile
runmysql:
	docker run -p 3306:3306 --name mysql -e MYSQL_ROOT_PASSWORD=secret -d mysql

startmysql:
	docker start mysql

stopmysql:
	docker stop mysql

createdb:
	docker exec mysql mysql -u root -psecret -e "CREATE DATABASE ecommerce"

dropdb:
	docker exec mysql mysql -u root -psecret -e "SET FOREIGN_KEY_CHECKS=0; DROP DATABASE IF EXISTS ecommerce; SET FOREIGN_KEY_CHECKS=1;"

seed:
	cd server && node seeder

startserver:
	cd server && npm start

startclient:
	cd client && pnpm start

.PHONY: runmysql startmysql stopmysql seed dropdb startserver startclient
```

## Database Setup Workflow

1. **Run MySQL Container**: `make runmysql`
2. **Create Database**: `make createdb`
3. **Seed Database**: `make seed`
4. **Start Server**: `make startserver`
5. **Start Client**: `make startclient`
