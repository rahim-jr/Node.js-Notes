# CSS Core Concepts

## Box Sizing
```css
box-sizing: border-box; /* Includes padding/border in width/height */
```

## CSS Variables
```css
:root {
  --primary-color: #3498db;
  --text-color: #2c3e50;
  --bg-light: #ecf0f1;
  --font-main: 'Arial', sans-serif;
}

.element {
  color: var(--primary-color);
}
```

## Z-Index
```css
z-index: 1000; /* Controls stacking order of positioned elements */
```

## Flex Wrap
```css
flex-wrap: wrap; /* Allows flex items to wrap to new lines */
```
